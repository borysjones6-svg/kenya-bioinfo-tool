Built for ICIPE attachment application.# Kenya Bioinfo Tool - FASTA Analyzer
Python tool for analyzing DNA sequences from NCBI - Built for ICIPE Bioinformatics attachment application.

## What it does
- Parses FASTA files
- Calculates sequence length, GC content, AT content
- Finds ATG start codons (for gene prediction)
- Built with Biopython

## Tools Used
Python, Biopython, Google Colab

## How to Run
python analyzer.py
